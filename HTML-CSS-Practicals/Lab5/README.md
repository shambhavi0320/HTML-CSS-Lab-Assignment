# Assignment 5: Links And Images

## Experiment Title
Links And Images.

## Aim
This experiment covers the following objectives: To create a home page containing a link to portfolio.html; To create a portfolio page with a heading and a link back to home.html; To display an image from the images folder with dimensions 200 by 200 and descriptive alternative text.

## Software / Tools Required
Computer, Git (for Assignments 1–2), a text editor (such as VS Code) and a modern web browser.

## Theory
- The anchor element creates hyperlinks. Its href attribute specifies the destination URL or file path.
- A relative hyperlink can navigate between files in the same folder.
- The img element embeds an image. The src attribute identifies the image file, alt provides text alternative, and width and height set dimensions.

## Task 1: Create a home page link to a portfolio

### Algorithm / Procedure
Create home.html with the heading and a paragraph containing the portfolio link.

### Input
Open home.html and click portfolio after portfolio.html is available.

### Output
The word portfolio is displayed as a clickable link to portfolio.html.

### Result
A working relative link to the portfolio page was added.

## Task 2: Create a portfolio page with a return link

### Algorithm / Procedure
Create portfolio.html; add a heading and an anchor pointing to home.html.

### Input
Open portfolio.html and click Back to Home.

### Output
The portfolio page appears and its link returns to home.html.

### Result
The two pages are connected using relative links.

## Task 3: Display an image with dimensions and alt text

### Algorithm / Procedure
Use the included sample illustration in images; set width and height to 200; add descriptive alt text.

### Input
Open portfolio-image.html. The supplied sample SVG is included in the images folder.

### Output
A 200 by 200 sample illustration appears under the heading.

### Result
An image was embedded with dimensions and descriptive alt text.
