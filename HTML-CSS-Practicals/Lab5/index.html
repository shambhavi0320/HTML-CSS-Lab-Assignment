HTML & CSS Practical Record

Lab 05: Links And Images

Practical tasks, programs, expected outputs and viva questions

Experiment No. 5
Complete the tasks below in order. Read the aim and procedure, study the program, and verify the expected output in your browser.
Task 1

Create a home page link to a portfolio

Aim: To create a home page containing a link to portfolio.html.

Theory: The anchor element creates hyperlinks. Its href attribute specifies the destination URL or file path.

Procedure: e Create home.html with the heading and a paragraph containing the portfolio link.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Home</title></head>
<body><h1>Welcome to My Site</h1><p>Visit my <a href="portfolio.html">portfolio</a>.</p></body></html>
Expected output: The word portfolio is displayed as a clickable link to portfolio.html.

Result: A working relative link to the portfolio page was added.

Viva-Voce Questions

  • Which element creates a link?
  • What is href?
  • What is a relative URL?
Task 2

Create a portfolio page with a return link

Aim: To create a portfolio page with a heading and a link back to home.html.

Theory: A relative hyperlink can navigate between files in the same folder.

Procedure: e Create portfolio.html; add a heading and an anchor pointing to home.html.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Portfolio</title></head>
<body><h1>My Portfolio</h1><p>Explore my learning projects and practice work.</p><a href="home.html">Back to Home</a></body></html>
Expected output: The portfolio page appears and its link returns to home.html.

Result: The two pages are connected using relative links.

Viva-Voce Questions

  • How do you link two local pages?
  • What does href contain?
  • What is a relative path?
Task 3

Display an image with dimensions and alt text

Aim: To display an image from the images folder with dimensions 200 by 200 and descriptive alternative text.

Theory: The img element embeds an image. The src attribute identifies the image file, alt provides text alternative, and width and height set dimensions.

Procedure: e Use the included sample illustration in images; set width and height to 200; add descriptive alt text.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Portfolio Image</title></head>
<body><h1>Portfolio Image</h1><img src="images/sample-portfolio.svg" width="200" height="200" alt="Illustration of a person representing a portfolio profile"></body></html>
Expected output: A 200 by 200 sample illustration appears under the heading.

Result: An image was embedded with dimensions and descriptive alt text.

Viva-Voce Questions

  • What does src specify?
  • Why is alt text important?
  • Which attributes set image dimensions?
