Lab 13: Flexbox Layouts

Practical tasks, programs, expected outputs and viva questions

Experiment No. 13
Complete the tasks below in order. Read the aim and procedure, study the program, and verify the expected output in your browser.
Task 1

Create a horizontal navigation bar with Flexbox

Aim: To arrange four navigation links horizontally using display:flex.

Theory: Flexbox is a one-dimensional layout model. `display:flex` creates a flex container whose direct children become flex items.

Procedure: e Create a nav element with four links; use display:flex, dark background and white link text.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Flex Navigation</title><style>nav{display:flex;gap:28px;background:#1d3557;padding:18px}nav a{color:white;text-decoration:none;font-family:Arial,sans-serif}</style></head>
<body><nav><a href="#home">Home</a><a href="#about">About</a><a href="#events">Events</a><a href="#contact">Contact</a></nav></body></html>
Expected output: A dark horizontal bar displays four white links side by side.

Result: A horizontal navigation bar was arranged using Flexbox.

Viva-Voce Questions

  • What is Flexbox?
  • What does display:flex do?
  • What is a flex item?
Task 2

Center three cards using Flexbox

Aim: To place three pricing cards in one row and center them using justify-content and align-items.

Theory: `justify-content` aligns flex items along the main axis; `align-items` aligns them along the cross axis.

Procedure: e Create a row container and three cards with the specified names and prices; apply Flexbox centering.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Centered Cards</title><style>.row{display:flex;justify-content:center;align-items:center;gap:18px;min-height:260px;flex-wrap:wrap}.card{width:150px;padding:18px;text-align:center;background:#eaf4f4;border:1px solid #457b9d;border-radius:10px}</style></head>
<body><h1>Plans</h1><div class="row"><div class="card"><h3>Starter</h3><p>₹199</p></div><div class="card"><h3>Standard</h3><p>₹349</p></div><div class="card"><h3>Premium</h3><p>₹499</p></div></div></body></html>
Expected output: Starter, Standard and Premium cards appear centered in one row when sufficient width is available.

Result: Three cards were centered using Flexbox alignment properties.

Viva-Voce Questions

  • What is the main axis?
  • What does justify-content do?
  • What does align-items do?
Task 3

Create a wrapping Flexbox card row

Aim: To display four stationery product cards that wrap onto additional rows on narrow screens.

Theory: The flex-wrap property controls whether flex items remain on one line or wrap onto multiple lines when space is limited.

Procedure: e Create four cards with the specified product names and prices; set display:flex and flex-wrap:wrap.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><meta name="viewport" content="width=device-width, initial-scale=1"><title>Stationery Shop</title><style>.products{display:flex;flex-wrap:wrap;gap:14px}.card{flex:1 1 180px;padding:20px;background:#f1f5f9;border:1px solid #94a3b8;border-radius:10px}</style></head>
<body><h1>Stationery Shop</h1><div class="products"><div class="card"><h2>Notebook</h2><p>₹60</p></div><div class="card"><h2>Pen</h2><p>₹15</p></div><div class="card"><h2>Bag</h2><p>₹350</p></div><div class="card"><h2>Book</h2><p>₹120</p></div></div></body></html>
Expected output: Cards occupy one or more rows depending on available width.

Result: A responsive wrapping card layout was created with flex-wrap.

Viva-Voce Questions

  • What does flex-wrap do?
  • What is flex-basis?
  • How does a flex container respond to limited width?
