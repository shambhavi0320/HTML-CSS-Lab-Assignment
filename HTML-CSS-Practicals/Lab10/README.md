# Assignment 10: Css Fundamentals

## Experiment Title
Css Fundamentals.

## Aim
This experiment covers the following objectives: To demonstrate internal CSS for h1 and highlight class and inline CSS for a paragraph; To style h1, .note, #title and all paragraph elements in an external stylesheet; To link style.css to an HTML page and apply its rules to selected elements.

## Software / Tools Required
Computer, Git (for Assignments 1–2), a text editor (such as VS Code) and a modern web browser.

## Theory
- CSS controls presentation. Internal CSS is written in a style element; inline CSS is written in an element style attribute.
- A type selector targets elements by tag name; a class selector begins with a dot; an id selector begins with #. External CSS is reusable across pages.
- The link element with rel="stylesheet" connects an external CSS file. The href path must point to the stylesheet location.

## Task 1: Apply inline and internal CSS

### Algorithm / Procedure
Add internal rules for h1 and .highlight; add an inline red paragraph style; open the page.

### Input
Open inline-internal.html in a browser.

### Output
The heading is navy, the inline paragraph is red and the highlighted paragraph has a yellow background.

### Result
Inline and internal CSS were applied successfully.

### Output
