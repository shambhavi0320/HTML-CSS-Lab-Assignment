Lab 10: Css Fundamentals

Practical tasks, programs, expected outputs and viva questions

Experiment No. 10
Complete the tasks below in order. Read the aim and procedure, study the program, and verify the expected output in your browser.
Task 1

Apply inline and internal CSS

Aim: To demonstrate internal CSS for h1 and highlight class and inline CSS for a paragraph.

Theory: CSS controls presentation. Internal CSS is written in a style element; inline CSS is written in an element style attribute.

Procedure: e Add internal rules for h1 and .highlight; add an inline red paragraph style; open the page.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>CSS Methods</title><style>h1{color:navy}.highlight{background-color:yellow}</style></head>
<body><h1>CSS Fundamentals</h1><p style="color:red">This paragraph uses inline CSS.</p><p class="highlight">This paragraph uses the highlight class.</p></body></html>
Expected output: The heading is navy, the inline paragraph is red and the highlighted paragraph has a yellow background.

Result: Inline and internal CSS were applied successfully.

Viva-Voce Questions

  • What is inline CSS?
  • Where is internal CSS written?
  • What is a class selector?
Task 2

Write CSS rules using element, class and id selectors

Aim: To style h1, .note, #title and all paragraph elements in an external stylesheet.

Theory: A type selector targets elements by tag name; a class selector begins with a dot; an id selector begins with #. External CSS is reusable across pages.

Procedure: e Create style.css and add the four required selector rules.

Program / Commands

h1 { color: navy; }
.note { font-style: italic; }
#title { text-decoration: underline; }
p { font-size: 18px; color: grey; }
Expected output: When linked, h1 is navy, note text is italic, title is underlined, and paragraphs are 18px grey.

Result: The requested CSS selectors and text styles were defined.

Viva-Voce Questions

  • What is a type selector?
  • How is a class selector written?
  • How is an id selector written?
Task 3

Link an external CSS file

Aim: To link style.css to an HTML page and apply its rules to selected elements.

Theory: The link element with rel="stylesheet" connects an external CSS file. The href path must point to the stylesheet location.

Procedure: e Create linked.html; link style.css in head; add h1 id title and two paragraphs class note.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>External CSS</title><link rel="stylesheet" href="style.css"></head>
<body><h1 id="title">External Stylesheet</h1><p class="note">CSS keeps presentation separate from structure.</p><p class="note">One stylesheet can style many elements.</p></body></html>
Expected output: The heading and paragraphs display the styles defined in style.css.

Result: The external stylesheet was linked and applied successfully.

Viva-Voce Questions

  • What is external CSS?
  • What does rel="stylesheet" mean?
  • What happens if the CSS path is incorrect?
