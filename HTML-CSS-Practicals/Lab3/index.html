Lab 03: Your First Html Page

Practical tasks, programs, expected outputs and viva questions

Experiment No. 3
Complete the tasks below in order. Read the aim and procedure, study the program, and verify the expected output in your browser.
Task 1

Create the first HTML page

Aim: To create an HTML document with a title and one main heading.

Theory: HTML provides the structure of a web page. The doctype declares HTML5; head contains metadata and title; body contains visible content.

Procedure: e Create first.html with the standard document structure; save and open it in a browser.

Program / Commands

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First Page</title>
</head>
<body>
  <h1>Hello, I am Asha.</h1>
</body>
</html>
Expected output: The browser tab displays “My First Page” and the page displays one large heading.

Result: The first HTML page was created and displayed successfully.

Viva-Voce Questions

  • What is HTML?
  • What is the purpose of the title element?
  • What does h1 represent?
Task 2

Use HTML headings and a paragraph

Aim: To create h1, h2, h3 headings and a paragraph.

Theory: HTML provides six heading levels, from h1 (highest importance) to h6. The p element represents a paragraph.

Procedure: e Create headings.html; add three heading levels and a paragraph; open it in a browser.

Program / Commands

<!DOCTYPE html>
<html lang="en">
<head><meta charset="UTF-8"><title>Headings</title></head>
<body>
  <h1>Web Technology</h1>
  <h2>HTML Basics</h2>
  <h3>Page Structure</h3>
  <p>HTML organizes content into meaningful elements.</p>
</body>
</html>
Expected output: Three headings appear in descending default sizes, followed by a paragraph.

Result: The page demonstrates heading hierarchy and paragraph content.

Viva-Voce Questions

  • How many HTML heading levels exist?
  • Which heading has the highest level?
  • Which element creates a paragraph?
Task 3

Format text using strong, em and br

Aim: To format text with semantic emphasis and insert a line break.

Theory: `strong` indicates strong importance and is usually bold. `em` adds emphasis and is usually italic. `br` creates a line break.

Procedure: e Create two paragraphs; apply strong and em to a word; insert br within one paragraph.

Program / Commands

<!DOCTYPE html>
<html lang="en">
<head><meta charset="UTF-8"><title>Text Formatting</title></head>
<body>
  <p>Learning HTML is <strong>important</strong> for web development.</p>
  <p>Practice every day to improve.<br><em>Keep learning!</em></p>
</body>
</html>
Expected output: The strong word appears bold, the em text appears italic, and br starts a new line.

Result: Text emphasis and a line break were added successfully.

Viva-Voce Questions

  • What is the difference between strong and b?
  • What does em mean?
  • Does br require a closing tag?
