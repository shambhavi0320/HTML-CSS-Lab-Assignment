# Assignment 3: Your First Html Page

## Experiment Title
Your First Html Page.

## Aim
This experiment covers the following objectives: To create an HTML document with a title and one main heading; To create h1, h2, h3 headings and a paragraph; To format text with semantic emphasis and insert a line break.

## Software / Tools Required
Computer, Git (for Assignments 1–2), a text editor (such as VS Code) and a modern web browser.

## Theory
- HTML provides the structure of a web page. The doctype declares HTML5; head contains metadata and title; body contains visible content.
- HTML provides six heading levels, from h1 (highest importance) to h6. The p element represents a paragraph.
- `strong` indicates strong importance and is usually bold. `em` adds emphasis and is usually italic. `br` creates a line break.

## Task 1: Create the first HTML page

### Algorithm / Procedure
Create first.html with the standard document structure; save and open it in a browser.

### Input
Open first.html in a web browser.

### Output
The browser tab displays “My First Page” and the page displays one large heading.

### Result
The first HTML page was created and displayed successfully.

## Task 2: Use HTML headings and a paragraph

### Algorithm / Procedure
Create headings.html; add three heading levels and a paragraph; open it in a browser.

### Input
Open headings.html in a browser.

### Output
Three headings appear in descending default sizes, followed by a paragraph.

### Result
The page demonstrates heading hierarchy and paragraph content.

## Task 3: Format text using strong, em and br

### Algorithm / Procedure
Create two paragraphs; apply strong and em to a word; insert br within one paragraph.

### Input
Open text-format.html in a browser.

### Output
The strong word appears bold, the em text appears italic, and br starts a new line.

### Result
Text emphasis and a line break were added successfully.
