Lab 15: Responsive Pages With Media Queries

Practical tasks, programs, expected outputs and viva questions

Experiment No. 15
Complete the tasks below in order. Read the aim and procedure, study the program, and verify the expected output in your browser.
Task 1

Create a mobile-first two-card layout

Aim: To stack two cards on small screens and place them side by side at 600px and above.

Theory: A mobile-first design starts with styles for small screens and uses min-width media queries to enhance layouts for wider screens. The viewport meta tag helps pages scale correctly on mobile devices.

Procedure: e Add viewport meta; define stacked cards as base styles; add a min-width:600px media query for two columns.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><meta name="viewport" content="width=device-width, initial-scale=1"><title>Mobile First</title><style>.cards{display:grid;grid-template-columns:1fr;gap:14px}.card{padding:20px;background:#eaf4f4;border:1px solid #457b9d;border-radius:10px}@media (min-width:600px){.cards{grid-template-columns:1fr 1fr}}</style></head>
<body><h1>Responsive Cards</h1><div class="cards"><section class="card"><h2>Card One</h2><p>This is the first content card.</p></section><section class="card"><h2>Card Two</h2><p>This is the second content card.</p></section></div></body></html>
Expected output: On narrow screens cards stack; at 600px and above they appear side by side.

Result: A mobile-first responsive card layout was implemented using a media query.

Viva-Voce Questions

  • What is mobile-first design?
  • What does min-width mean in a media query?
  • Why use the viewport meta tag?
Task 2

Make an image responsive

Aim: To make an image shrink to fit its container while maintaining its aspect ratio.

Theory: `max-width:100%` prevents an image from exceeding its parent width. `height:auto` preserves the image aspect ratio as width changes.

Procedure: e Add a heading and the included sample image; apply max-width:100% and height:auto.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><meta name="viewport" content="width=device-width, initial-scale=1"><title>Responsive Image</title><style>img{max-width:100%;height:auto;display:block;border-radius:12px}</style></head>
<body><h1>Responsive Image</h1><img src="images/sample-portfolio.svg" alt="Illustration of a person representing a portfolio profile"></body></html>
Expected output: The image scales down to fit a narrow container and preserves its proportions.

Result: A responsive image was created using max-width and automatic height.

Viva-Voce Questions

  • What does max-width:100% do?
  • Why use height:auto?
  • What is an image aspect ratio?
Task 3

Change heading size with a media query

Aim: To set base text sizes in rem and enlarge the h1 at viewport widths of 600px and above.

Theory: The rem unit is relative to the root font size. Media queries apply CSS only when their conditions match the viewport or device.

Procedure: e Set body font-size to 1rem and h1 to 1.5rem; add min-width:600px rule setting h1 to 2.5rem.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><meta name="viewport" content="width=device-width, initial-scale=1"><title>Responsive Text</title><style>body{font-size:1rem;font-family:Arial,sans-serif}h1{font-size:1.5rem}@media (min-width:600px){h1{font-size:2.5rem}}</style></head>
<body><h1>Responsive Typography</h1><p>The heading changes size when the viewport reaches 600 pixels.</p></body></html>
Expected output: The heading is 1.5rem on narrow screens and 2.5rem at 600px and above.

Result: Responsive heading typography was implemented with rem units and a media query.

Viva-Voce Questions

  • What is rem?
  • What is a media query?
  • What does min-width:600px mean?
