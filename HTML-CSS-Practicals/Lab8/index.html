Lab 08: Sign-Up Forms And Choices

Practical tasks, programs, expected outputs and viva questions

Experiment No. 8
Complete the tasks below in order. Read the aim and procedure, study the program, and verify the expected output in your browser.
Task 1

Create a labelled sign-up form

Aim: To create a POST form with labelled full-name, email and password fields.

Theory: The form element groups controls. Labels improve usability and accessibility when their for attribute matches the input id. Password inputs conceal typed characters.

Procedure: e Create form with method post and action thanks.html; add three associated labels and inputs.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Sign Up</title></head>
<body><h1>Create an Account</h1><form method="post" action="thanks.html">
<label for="full-name">Full name</label><input id="full-name" name="fullName" type="text"><br><br>
<label for="email">Email</label><input id="email" name="email" type="email"><br><br>
<label for="password">Password</label><input id="password" name="password" type="password"><br><br>
<button type="submit">Sign Up</button></form></body></html>
Expected output: Three labelled fields appear. Password characters are masked while typing.

Result: A sign-up form with correctly associated labels and input types was created.

Viva-Voce Questions

  • What does method="post" mean?
  • Why connect label and input?
  • What does type="password" do?
Task 2

Add radio buttons and a course dropdown

Aim: To create two gender radio choices and a course dropdown with BCA and B.Tech.

Theory: Radio inputs with the same name form a mutually exclusive group. The select element creates a dropdown and option defines each choice.

Procedure: e Create a gender fieldset with two radio inputs sharing a name; add a select with two options.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Choices</title></head>
<body><h1>Choose Your Details</h1><form><fieldset><legend>Gender</legend>
<label><input type="radio" name="gender" value="Female"> Female</label>
<label><input type="radio" name="gender" value="Male"> Male</label>
</fieldset><br><label for="course">Course</label>
<select id="course" name="course"><option value="BCA">BCA</option><option value="B.Tech">B.Tech</option></select></form></body></html>
Expected output: Only one radio option can be selected at a time; the dropdown contains BCA and B.Tech.

Result: Radio choices and a course dropdown were implemented successfully.

Viva-Voce Questions

  • Why do radio buttons share a name?
  • Which element creates a dropdown?
  • What does option define?
Task 3

Use required fields and a placeholder

Aim: To make full-name and email fields mandatory and provide a placeholder for the name field.

Theory: The required attribute triggers browser validation before form submission. A placeholder gives a short input hint but does not replace a label.

Procedure: e Create full-name and email inputs; add required to both; add a name placeholder and submit button.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Required Sign Up</title></head>
<body><h1>Quick Sign Up</h1><form action="#">
<label for="name">Full name</label><input id="name" name="name" type="text" placeholder="Enter your full name" required><br><br>
<label for="email">Email</label><input id="email" name="email" type="email" required><br><br>
<button type="submit">Submit</button></form></body></html>
Expected output: The browser displays a validation prompt when a required field is empty.

Result: Required validation and a placeholder were added to the sign-up form.

Viva-Voce Questions

  • What does required do?
  • What is a placeholder?
  • Does placeholder replace a label?
