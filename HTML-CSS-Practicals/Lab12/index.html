Lab 12: Box Model, Cards And Scrolling

Practical tasks, programs, expected outputs and viva questions

Experiment No. 12
Complete the tasks below in order. Read the aim and procedure, study the program, and verify the expected output in your browser.
Task 1

Compare content-box and border-box

Aim: To compare two boxes with equal width, padding and border but different box-sizing values.

Theory: In content-box, declared width applies to content and padding/border are added outside. In border-box, declared width includes content, padding and border.

Procedure: e Create two div boxes with width 200px, padding 20px and border 5px; apply different box-sizing values.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Box Model</title><style>.box{width:200px;padding:20px;border:5px solid #1d3557;margin:16px;background:#dbeafe}.content{box-sizing:content-box}.border{box-sizing:border-box}</style></head>
<body><h1>CSS Box Model</h1><div class="box content">content-box</div><div class="box border">border-box</div></body></html>
Expected output: The content-box element has a larger outer width than the border-box element.

Result: The effect of the two box-sizing values was demonstrated.

Viva-Voce Questions

  • What are the four parts of the box model?
  • What does content-box include in width?
  • What does border-box include in width?
Task 2

Style a card component

Aim: To create a card with background colour, 2px border, 12px rounded corners and 16px padding.

Theory: A card is a common UI component used to group related content. CSS background, border, border-radius and padding control its appearance and spacing.

Procedure: e Create a div with class card; place an h3 and paragraph inside; apply the specified styles.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Card Component</title><style>.card{max-width:320px;background:#eaf4f4;border:2px solid #457b9d;border-radius:12px;padding:16px;font-family:Arial,sans-serif}</style></head>
<body><div class="card"><h3>Learning Card</h3><p>This card groups a heading and a short description in one neat component.</p></div></body></html>
Expected output: A coloured card appears with a 2px border, rounded corners and internal spacing.

Result: A styled card component was created successfully.

Viva-Voce Questions

  • What does padding control?
  • What does border-radius do?
  • Why group content in a card?
Task 3

Create a scrollable content box

Aim: To create a fixed-height box with automatic overflow scrolling and five paragraphs.

Theory: The overflow property controls content that exceeds an element’s box. `overflow: auto` adds scrollbars when content requires them.

Procedure: e Create a 120px-high div; set overflow:auto; add five paragraph lines.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Scrollable Box</title><style>.scroll-box{height:120px;overflow:auto;border:2px solid #1d3557;padding:10px;width:280px}</style></head>
<body><h1>Scrollable Content</h1><div class="scroll-box"><p>Line 1</p><p>Line 2</p><p>Line 3</p><p>Line 4</p><p>Line 5</p></div></body></html>
Expected output: The fixed-height box displays a scrollbar because the five lines exceed its height.

Result: A scrollable box was created using overflow:auto.

Viva-Voce Questions

  • What does overflow control?
  • What does overflow:auto do?
  • Why set a fixed height?
