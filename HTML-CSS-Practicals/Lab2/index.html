Lab 02: Pushing And Cloning A Repository

Practical tasks, programs, expected outputs and viva questions

Experiment No. 2
Complete the tasks below in order. Read the aim and procedure, study the program, and verify the expected output in your browser.
Task 1

Create and inspect a bare remote repository

Aim: To create a bare repository and add it as the origin remote.

Theory: A bare repository stores Git data without a working directory and is commonly used as a remote. `git remote -v` lists remote URLs for fetch and push.

Procedure: e From html-lab, create ../html-remote as a bare repository; add origin; inspect remotes.

Program / Commands

git init --bare ../html-remote
git remote add origin ../html-remote
git remote -v
Expected output: The output lists origin with the same path for fetch and push.

Result: A bare remote repository was created and connected as origin.

Viva-Voce Questions

  • What is a bare repository?
  • What is origin?
  • What does git remote -v show?
Task 2

Push commits to the remote repository

Aim: To transfer local commits to the configured remote repository.

Theory: `git push` sends local commits to a remote branch. The branch may be named main or master depending on repository configuration.

Procedure: e Check the current branch; push it to origin using the matching branch name.

Program / Commands

git branch --show-current
# If the branch is main:
git push origin main
# If the branch is master, use instead:
git push origin master
Expected output: Git confirms that the local branch was pushed to the corresponding remote branch.

Result: The local commit history was pushed successfully to origin.

Viva-Voce Questions

  • What does git push do?
  • What is a branch?
  • Why might a repository use main or master?
Task 3

Clone the remote repository

Aim: To create a working copy by cloning the remote repository and inspect its history.

Theory: `git clone` copies a repository, including its commit history, into a new directory.

Procedure: e Move to the parent directory; clone html-remote into html-copy; enter it; view the log.

Program / Commands

cd ..
git clone html-remote html-copy
cd html-copy
git log --oneline
Expected output: The cloned repository shows the same commits as the source repository.

Result: The remote repository was cloned and its commit history was verified.

Viva-Voce Questions

  • What does git clone do?
  • Does cloning copy commit history?
  • What is a working directory?
