Lab 04: Divs, Attributes And A Small Fix

Practical tasks, programs, expected outputs and viva questions

Experiment No. 4
Complete the tasks below in order. Read the aim and procedure, study the program, and verify the expected output in your browser.
Task 1

Group page regions using div elements

Aim: To group page content into header, main and footer blocks.

Theory: The div element is a generic block container. Class attributes identify groups of elements for styling or scripting.

Procedure: e Create three div elements and assign the required classes.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Layout Blocks</title></head>
<body>
  <div class="header">Website Header</div>
  <div class="main">Main content goes here.</div>
  <div class="footer">Website Footer</div>
</body></html>
Expected output: Three text blocks appear in header, main and footer order.

Result: The page content was grouped into three div blocks.

Viva-Voce Questions

  • What is a div?
  • What is a class attribute?
  • Can multiple elements share a class?
Task 2

Use id and custom data attributes

Aim: To create a div with id profile and a paragraph with data-topic="hobbies".

Theory: The id attribute uniquely identifies an element in a document. Custom data attributes begin with `data-` and store page-specific information.

Procedure: e Create the profile div; place a paragraph inside it; add the required data attribute.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Attributes</title></head>
<body>
  <div id="profile">
    <p data-topic="hobbies">Reading, music and photography are my hobbies.</p>
  </div>
</body></html>
Expected output: The paragraph text is visible. The data-topic value is stored in the element and is not displayed automatically.

Result: The id and custom data attribute were applied successfully.

Viva-Voce Questions

  • What is the purpose of id?
  • What prefix is used for custom data attributes?
  • Are data attributes automatically visible?
Task 3

Correct errors in an HTML page

Aim: To correct malformed heading and paragraph tags in the attendance report.

Theory: HTML elements should be properly opened and closed. Correct nesting and closing tags help browsers interpret document structure consistently.

Procedure: e Add the missing closing h1 tag; correct the second p opening tag; save the corrected page.

Program / Commands

<!DOCTYPE html>
<html lang="en">
<head><meta charset="UTF-8"><title>Attendance</title></head>
<body>
  <h1>Attendance Report</h1>
  <p>Asha: 92%</p>
  <p>Rohan: 85%</p>
</body>
</html>
Expected output: The page shows the Attendance Report heading and two separate attendance lines.

Result: The malformed HTML was corrected and the attendance report displays properly.

Viva-Voce Questions

  • Why should HTML tags be closed?
  • What is proper nesting?
  • Which tag represents a paragraph?
