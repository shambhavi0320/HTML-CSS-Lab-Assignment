# Assignment 4: Divs, Attributes And A Small Fix

## Experiment Title
Divs, Attributes And A Small Fix.

## Aim
This experiment covers the following objectives: To group page content into header, main and footer blocks; To create a div with id profile and a paragraph with data-topic="hobbies"; To correct malformed heading and paragraph tags in the attendance report.

## Software / Tools Required
Computer, Git (for Assignments 1–2), a text editor (such as VS Code) and a modern web browser.

## Theory
- The div element is a generic block container. Class attributes identify groups of elements for styling or scripting.
- The id attribute uniquely identifies an element in a document. Custom data attributes begin with `data-` and store page-specific information.
- HTML elements should be properly opened and closed. Correct nesting and closing tags help browsers interpret document structure consistently.

## Task 1: Group page regions using div elements

### Algorithm / Procedure
Create three div elements and assign the required classes.

### Input
Open layout.html in a browser.

### Output
Three text blocks appear in header, main and footer order.

### Result
The page content was grouped into three div blocks.

## Task 2: Use id and custom data attributes

### Algorithm / Procedure
Create the profile div; place a paragraph inside it; add the required data attribute.

### Input
Open attributes.html; inspect the paragraph in browser developer tools if needed.

### Output
The paragraph text is visible. The data-topic value is stored in the element and is not displayed automatically.

### Result
The id and custom data attribute were applied successfully.

## Task 3: Correct errors in an HTML page

### Algorithm / Procedure
Add the missing closing h1 tag; correct the second p opening tag; save the corrected page.

### Input
Open attendance-fixed.html in a browser.

### Output
The page shows the Attendance Report heading and two separate attendance lines.

### Result
The malformed HTML was corrected and the attendance report displays properly.
