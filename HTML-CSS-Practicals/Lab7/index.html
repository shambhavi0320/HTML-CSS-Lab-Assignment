Task 1

Build a semantic About Me page

Aim: To create a page with header navigation, an about section and a contact footer.

Theory: Semantic HTML elements such as header, nav, main, section and footer describe the purpose of page regions. Fragment links use an element id as their destination.

Procedure: e Create header with heading and two navigation links; add main section id about; add footer id contact with a mailto link.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><meta name="viewport" content="width=device-width, initial-scale=1"><title>About Me</title></head>
<body>
<header><h1>About Me</h1><nav><a href="#about">About</a> | <a href="#contact">Contact</a></nav></header>
<main><section id="about"><h2>About me</h2><p>I am a learner interested in web design, technology and creative projects.</p></section></main>
<footer id="contact"><p>Contact: <a href="mailto:hello@example.com">hello@example.com</a></p></footer>
</body></html>
Expected output: The page shows a heading and two navigation links; About jumps to the section and Contact jumps to the footer email link.

Result: A semantic About Me page with in-page navigation and a mailto link was created.

Viva-Voce Questions

  • What is semantic HTML?
  • What does href="#about" do?
  • What is the purpose of mailto:?
