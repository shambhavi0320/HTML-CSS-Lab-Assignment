Lab 11: Units And Css Variables

Practical tasks, programs, expected outputs and viva questions

Experiment No. 11
Complete the tasks below in order. Read the aim and procedure, study the program, and verify the expected output in your browser.
Task 1

Use px, percentage and rem units

Aim: To compare fixed and relative CSS units by creating two boxes and larger paragraph text.

Theory: px is a fixed CSS length unit; % is relative to a containing block; rem is relative to the root element font size.

Procedure: e Create a 200px by 40px box, a 50% by 40px box and a paragraph with 1.5rem font size.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><meta name="viewport" content="width=device-width, initial-scale=1"><title>CSS Units</title><style>.fixed{width:200px;height:40px;background:#457b9d;margin:10px 0}.half{width:50%;height:40px;background:#a8dadc;margin:10px 0}p{font-size:1.5rem}</style></head>
<body><h1>CSS Units</h1><div class="fixed">200px wide</div><div class="half">50% wide</div><p>This paragraph uses 1.5rem text.</p></body></html>
Expected output: The first box is 200px wide; the second occupies half its container; paragraph text is larger.

Result: The px, percentage and rem units were demonstrated.

Viva-Voce Questions

  • What is px?
  • What is percentage width relative to?
  • What does rem depend on?
Task 2

Define and use CSS custom properties

Aim: To define three CSS variables in :root and use them for page colour, padding and heading colour.

Theory: CSS custom properties are declared with a `--` prefix and accessed using var(). Defining variables in :root makes them available throughout the document.

Procedure: e Declare --main-color, --accent-color and --page-padding in :root; apply them to body and h1.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>CSS Variables</title><style>:root{--main-color:#1d3557;--accent-color:#e63946;--page-padding:20px}body{color:var(--main-color);padding:var(--page-padding);font-family:Arial,sans-serif}h1{color:var(--accent-color)}</style></head>
<body><h1>Reusable CSS Variables</h1><p>This text uses the main colour and page spacing from custom properties.</p></body></html>
Expected output: The heading uses accent red; body text uses the main navy colour and page padding is 20px.

Result: CSS variables were declared and reused with var().

Viva-Voce Questions

  • How are CSS variables named?
  • What does :root select?
  • How do you use a CSS variable?
Task 3

Create reusable design tokens in CSS

Aim: To define primary colour, accent colour, heading size and spacing tokens and apply them to page styles.

Theory: Design tokens are reusable values stored as custom properties. They make design updates consistent and reduce repeated literal values.

Procedure: e Create tokens.css with the four specified variables; use them for body colour and padding and h1 colour and size.

Program / Commands

:root {
  --primary-color: #1d3557;
  --accent-color: #e63946;
  --heading-size: 2rem;
  --spacing: 16px;
}
body { color: var(--primary-color); padding: var(--spacing); }
h1 { color: var(--accent-color); font-size: var(--heading-size); }
Expected output: The linked page uses navy body text, 16px padding, red h1 text and a 2rem heading size.

Result: Reusable CSS design tokens were defined and applied.

Viva-Voce Questions

  • What is a design token?
  • Why use custom properties?
  • What does var() do?
