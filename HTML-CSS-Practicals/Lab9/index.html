Lab 09: Tables With Headers And Footers

Practical tasks, programs, expected outputs and viva questions

Experiment No. 9
Complete the tasks below in order. Read the aim and procedure, study the program, and verify the expected output in your browser.
Task 1

Create a marks table with header and body

Aim: To create a captioned table with a header and three student records.

Theory: The table element represents tabular data. Caption describes the table; thead groups headings and tbody groups data rows.

Procedure: e Create a caption; add Name, Maths and Science headings; add the three specified rows.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Class Marks</title></head>
<body><table border="1"><caption>Marks of Class A</caption><thead><tr><th>Name</th><th>Maths</th><th>Science</th></tr></thead><tbody>
<tr><td>Asha</td><td>78</td><td>85</td></tr><tr><td>Rohan</td><td>64</td><td>70</td></tr><tr><td>Neha</td><td>91</td><td>88</td></tr>
</tbody></table></body></html>
Expected output: A table appears with a caption, three column headings and three student rows.

Result: The marks table was created with thead and tbody.

Viva-Voce Questions

  • What is caption used for?
  • What is thead?
  • What is tbody?
Task 2

Add a table footer with class averages

Aim: To create a marks table for Asha and Rohan and calculate the subject averages in tfoot.

Theory: The tfoot element groups summary rows. Average is calculated as sum of values divided by the number of values. Maths average=(78+64)/2=71; Science average=(85+70)/2=77.5.

Procedure: e Use the same caption and headings; add Asha and Rohan; add a footer row containing the calculated averages.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Marks Average</title></head>
<body><table border="1"><caption>Marks of Class A</caption><thead><tr><th>Name</th><th>Maths</th><th>Science</th></tr></thead><tbody>
<tr><td>Asha</td><td>78</td><td>85</td></tr><tr><td>Rohan</td><td>64</td><td>70</td></tr>
</tbody><tfoot><tr><th>Class average</th><td>71</td><td>77.5</td></tr></tfoot></table></body></html>
Expected output: The footer displays Maths average 71 and Science average 77.5.

Result: The table footer and correct class averages were added.

Viva-Voce Questions

  • How is an average calculated?
  • What is tfoot?
  • Why separate table sections?
Task 3

Add scope attributes to table headers

Aim: To improve table accessibility using scope="col" and scope="row".

Theory: The scope attribute indicates whether a header applies to a row or column, helping assistive technologies interpret table relationships.

Procedure: e Add scope="col" to each column header and scope="row" to each student-name header cell.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Accessible Marks</title></head>
<body><table border="1"><caption>Marks of Class A</caption><thead><tr><th scope="col">Name</th><th scope="col">Maths</th><th scope="col">Science</th></tr></thead><tbody>
<tr><th scope="row">Asha</th><td>78</td><td>85</td></tr><tr><th scope="row">Rohan</th><td>64</td><td>70</td></tr>
</tbody></table></body></html>
Expected output: The table looks like a standard marks table; header cells carry the requested scope attributes.

Result: Scope attributes were added to improve table accessibility.

Viva-Voce Questions

  • What does scope="col" mean?
  • What does scope="row" mean?
  • How does scope help screen readers?
