Lab 14: Css Grid Layouts

Practical tasks, programs, expected outputs and viva questions

Experiment No. 14
Complete the tasks below in order. Read the aim and procedure, study the program, and verify the expected output in your browser.
Task 1

Create a three-column CSS Grid

Aim: To arrange six numbered boxes in three equal columns with a 12px gap.

Theory: CSS Grid is a two-dimensional layout system. `grid-template-columns` defines column tracks and the fr unit distributes available space proportionally.

Procedure: e Create six div boxes; set display:grid; define three 1fr columns and 12px gap.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>First Grid</title><style>.grid{display:grid;grid-template-columns:repeat(3,1fr);gap:12px}.grid div{padding:28px;text-align:center;background:#dbeafe;border:1px solid #457b9d;font-size:24px}</style></head>
<body><h1>Three-Column Grid</h1><div class="grid"><div>1</div><div>2</div><div>3</div><div>4</div><div>5</div><div>6</div></div></body></html>
Expected output: Six boxes appear in two rows with three equal columns and 12px gaps.

Result: A three-column CSS Grid was created successfully.

Viva-Voce Questions

  • What is CSS Grid?
  • What does 1fr mean?
  • What does gap control?
Task 2

Create a responsive photo gallery grid

Aim: To create six gallery boxes using auto-fill and minmax for responsive columns.

Theory: `repeat()` avoids repeating track definitions. `auto-fill` creates as many tracks as fit; `minmax()` sets a minimum and maximum track size.

Procedure: e Create a heading and six labelled boxes; use repeat(auto-fill,minmax(150px,1fr)) and 10px gap.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><meta name="viewport" content="width=device-width, initial-scale=1"><title>Club Photo Gallery</title><style>.gallery{display:grid;grid-template-columns:repeat(auto-fill,minmax(150px,1fr));gap:10px}.photo{min-height:110px;display:grid;place-items:center;background:#e0e7ff;border:1px solid #818cf8;border-radius:8px}</style></head>
<body><h1>Club Photo Gallery</h1><div class="gallery"><div class="photo">Photo 1</div><div class="photo">Photo 2</div><div class="photo">Photo 3</div><div class="photo">Photo 4</div><div class="photo">Photo 5</div><div class="photo">Photo 6</div></div></body></html>
Expected output: More boxes fit in each row as the viewport becomes wider; each track remains at least 150px wide.

Result: A responsive gallery layout was created using CSS Grid functions.

Viva-Voce Questions

  • What does repeat() do?
  • What does minmax() define?
  • What is auto-fill?
Task 3

Build a dashboard using named grid areas

Aim: To create a two-column dashboard with header and footer spanning both columns.

Theory: The grid-template-areas property names regions of a grid. Each string row describes the placement of named areas.

Procedure: e Define 200px and 1fr columns; name header, sidebar, main and footer areas; assign each element.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><meta name="viewport" content="width=device-width, initial-scale=1"><title>Dashboard Areas</title><style>.dashboard{display:grid;grid-template-columns:200px 1fr;grid-template-areas:"header header" "sidebar main" "footer footer";gap:10px}.dashboard>*{padding:22px;background:#eaf4f4;border:1px solid #457b9d}.header{grid-area:header}.sidebar{grid-area:sidebar}.main{grid-area:main;min-height:160px}.footer{grid-area:footer}</style></head>
<body><div class="dashboard"><header class="header">Header</header><aside class="sidebar">Sidebar</aside><main class="main">Main area</main><footer class="footer">Footer</footer></div></body></html>
Expected output: Header spans the top, sidebar is on the left, main is on the right and footer spans the bottom.

Result: A dashboard layout was built using named grid areas.

Viva-Voce Questions

  • What is grid-template-areas?
  • How do you make an area span columns?
  • What does 1fr represent?
