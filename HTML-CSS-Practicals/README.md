# HTML-CSS-Practicals

A practical-record folder organized into 15 lab folders.

## Folder structure
Each lab contains:
- `index.html`
- `style.css`
- `README.md`
- `images/screenshot.png`

## Open a lab
Open any `Lab1` ... `Lab15` folder in VS Code and run its `index.html` with Live Server or a browser.

**Screenshot note:** `images/screenshot.png` is a labelled placeholder, not a captured browser result. Replace it with your actual practical output screenshot.

**Source note:** Content is based on the uploaded *HTML and CSS Lab Practical Record*. Experiment 7 in that document contains only one task; the missing tasks have not been fabricated.
