Lab 06: Types Of Html Lists

Practical tasks, programs, expected outputs and viva questions

Experiment No. 6
Complete the tasks below in order. Read the aim and procedure, study the program, and verify the expected output in your browser.
Task 1

Create an unordered shopping list

Aim: To display three shopping items using an unordered list.

Theory: The ul element creates a bulleted list. Each list item is represented by li.

Procedure: e Create a heading and a ul containing Notebook, Pen and Bag.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Shopping List</title></head>
<body><h1>Shopping List</h1><ul><li>Notebook</li><li>Pen</li><li>Bag</li></ul></body></html>
Expected output: Three bullet points appear for Notebook, Pen and Bag.

Result: The unordered shopping list was created successfully.

Viva-Voce Questions

  • What is ul?
  • Which element represents a list item?
  • How does ul differ from ol?
Task 2

Create an ordered list with a nested list

Aim: To create a numbered canteen menu with a nested numbered list under Sandwich.

Theory: The ol element creates an ordered list. Lists can be nested by placing another ol inside an li element.

Procedure: e Add Samosa and Sandwich as ordered items; nest Cheese and Vegetable under Sandwich.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Canteen Menu</title></head>
<body><h1>Canteen Menu</h1><ol><li>Samosa</li><li>Sandwich<ol><li>Cheese</li><li>Vegetable</li></ol></li></ol></body></html>
Expected output: Two numbered main items appear, with two nested numbered choices under Sandwich.

Result: A nested ordered list was created successfully.

Viva-Voce Questions

  • What is ol?
  • How is a nested list created?
  • Can an ordered list contain another ordered list?
Task 3

Create a description list for FAQs

Aim: To display two questions and their answers using a description list.

Theory: The dl element groups terms and descriptions. The dt element identifies a term and dd provides its description.

Procedure: e Create two dt elements and add an answer in a dd element after each question.

Program / Commands

<!DOCTYPE html>
<html lang="en"><head><meta charset="UTF-8"><title>Library FAQ</title></head>
<body><h1>Library FAQ</h1><dl><dt>How many books can I borrow?</dt><dd>You can borrow up to three books at a time.</dd><dt>Is the library open on Sunday?</dt><dd>The library remains closed on Sunday.</dd></dl></body></html>
Expected output: Each question is followed by its answer.

Result: A description list with two FAQ entries was created.

Viva-Voce Questions

  • What is dl?
  • What is the role of dt?
  • What is the role of dd?
